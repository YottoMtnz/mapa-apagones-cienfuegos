# Reportes y correcciones en la versión 3.0

La información oficial procede del canal de Cienfuegos. Los reportes comunitarios
son opcionales y se reciben mediante el Worker descrito en worker/DESPLEGAR.md.
No se expone ni se usa un token de Telegram en el navegador.

Las correcciones geográficas se guardan localmente hasta que el usuario decide
enviar un issue de GitHub. El panel Apps Script opcional registra decisiones
protegidas por ADMIN_TOKEN; no publica coordenadas automáticamente.

Consulta LEEME_PRIMERO.txt para la instalación y las limitaciones.
