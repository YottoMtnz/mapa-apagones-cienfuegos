# ⚡ Mapa de Apagones — Cienfuegos

Mapa interactivo en vivo de los apagones en la provincia de Cienfuegos, Cuba.

🗺️ **Ver el mapa:** https://yottomtnz.github.io/mapa-apagones-cienfuegos/

## Cómo funciona

- 🔴 Puntos **rojos parpadeantes**: circuitos sin servicio eléctrico
- 🟢 Puntos **verdes**: circuitos con servicio
- Toca un punto para ver el número de circuito, lugares y municipio
- Los datos se actualizan automáticamente cada 5 minutos

## Fuente de datos

Los datos provienen del canal oficial de Telegram **[Empresa Eléctrica Cienfuegos](https://t.me/empresaelectricacienfuegos1)**, que publica la programación de apagones y circuitos afectados.
